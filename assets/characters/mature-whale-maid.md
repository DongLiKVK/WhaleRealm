# 角色设定卡 · 成熟比例鲸鱼娘

- 记忆锚点名：**成熟比例鲸鱼娘**（Mature-Proportion Whale Girl）
- 别名：成熟鲸鱼女仆 / 蓝鲸女仆（正式服装为深蓝白女仆装）

## 一、体型与头身（区别于 Q 版鲸鱼娘的关键）

- 成熟比例：身形修长，腰线清晰，腿部比例较长，头身比接近成年女性。
- 站姿自然放松，双手交叠于围裙前，重心稳；三视图（正 / 侧 / 背）保持同一套服装结构与配色。
- 与旧短裙版本的最大差异：**裙长由短裙改为落在小腿中段**，线条优雅、垂坠适度。

## 二、发型与发色

- 发量浓密，长度延伸到**腰臀以下**，长发从两肩向外铺开，末端层层波浪卷。
- 渐变：发根**深海蓝** → 发束穿插**钴蓝**光泽 → 越近发尾转为**明亮海蓝 / 浅青蓝**。
- 前发：轻覆额头的**侧分斜刘海**，脸颊旁留着向内弯曲的短发。
- 头顶一根**细长呆毛**自然向上弯起（识别特征）。
- 后脑上层头发编成**一圈细辫**，垂落长发之间系**蓝色蝴蝶结**。

## 三、面部

- 轮廓纤细柔和；眼睛为明亮**杏仁形**，深蓝外圈包裹渐变至亮蓝的虹膜，点缀清晰浅色高光。
- 神情开朗亲切，双眼有神、眼尾自然舒展，嘴角扬起轻松真诚的笑容，脸颊带淡淡红晕。

## 四、头部饰物

- 白色层叠蕾丝女仆发箍，两侧各一个**亮蓝色小蝴蝶结**。
- 头侧伸出一对**横向舒展的深蓝色鲸鱼鳍状耳朵**，鳍内侧衬白色波浪褶边。

## 五、服装（深蓝 × 白 女仆装）

- 领：白色立领 + 深蓝领结，领结中央镶**椭圆形蓝宝石**，细金边。
- 胸：带纵向褶裥、纽扣与蕾丝边的白色布料；两肩白色荷叶边肩饰。
- 袖：深蓝色微蓬袖，袖口收紧并露出白色花边；袖上有小十字星刺绣。
- 腰：贴合身形的深蓝腰封，正面两行小巧**金色纽扣**。
- 裙：深蓝裙摆自腰部自然展开，长度至小腿中段；叠层次分明的白色荷叶边与蕾丝，裙面点缀**细小金色十字星**与精致装饰线，并有深蓝小蝴蝶结。
- 围裙：正面白色围裙，下缘柔和波浪形镶花边，近裙角处印**蓝色小鲸鱼图案**。
- 背：宽大**白色蝴蝶结**，缎带顺裙摆垂落。

## 六、鲸尾与腿部

- 腰后伸出**深海蓝鲸尾**，略带柔和光泽，向外下方延伸，末端展开为两片宽大尾鳍，**鳍缘渐变为浅蓝**。
- 双腿：白色过膝长袜，袜口饰蕾丝与深蓝小蝴蝶结。
- 鞋：深蓝圆头**玛丽珍鞋**，脚背横带配金色圆扣，稳重方形中跟。

## 七、配色板

| 用途 | 颜色 | 说明 |
| --- | --- | --- |
| 主色 | 深海蓝 #1B2A5E 级 | 裙身、腰封、袖子、鲸尾根 |
| 辅色 | 钴蓝 #2F5BD0 级 | 发束光泽、蝴蝶结、宝石 |
| 亮点 | 浅青蓝 #7FD4F0 级 | 发尾、尾鳍边缘、虹膜高光 |
| 中和 | 纯白 / 米白 | 围裙、蕾丝、立领、长袜 |
| 点缀 | 少量金色 | 纽扣、领结金边、裙面十字星 |

## 八、一致性硬约束（再绘制时不可漂移）

1. 头身比必须维持**成年女性**成熟比例，禁止回退为 Q 版 / 萝莉头身。
2. 裙长必须**到小腿中段**（不是短裙）。
3. 头顶**呆毛 + 鲸鳍耳 + 后脑细辫蝴蝶结**三件套同时存在。
4. 鲸尾自**腰后**伸出，尾鳍两片、边缘浅蓝渐变。
5. 围裙上**蓝色小鲸鱼**图案不可省略。
6. 主色永远是深海蓝 / 钴蓝 / 浅青蓝 / 白，金色只作细节点缀。
