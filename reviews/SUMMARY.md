## 一句话结论

**作为「演示皮肤」是 8.5 分，作为「DSH 中文社区论坛」只有 4 分。**
读的路径做到了能上线的水平（三栏信息密度、分类×标签双维度、本帖导航、零横向溢出、夜间皮肤），写的路径一条都没通（发帖是 toast、回复不落地、通知是死链、刷新即失），而插件生态最关键的「插件 ↔ 讨论」在数据层就断成两座孤岛。手机上还有第二条断口：论坛 / 市场 / 我的空间三个主路由**没有任何入口**。

## 三家交叉得出的「只改三件事」（三方独立给出、高度重合）

### P0-1　把「写」这条路打通（决定它是论坛还是论坛截图）
- 回复真落楼层：\`S.floors\` 增加一条并把 \`#reply\` 内容追加，而不是 toast（js/app.js:863-868）
- 发新帖给出真编辑器（弹层或行内），提交后进 \`threads\` 顶部（js/app.js:456）
- 全站状态落 \`localStorage\`：已读、已装、已赞、草稿、新发内容，刷新不丢（现在 render 全量重绘即失，js/app.js:727）
- 通知行可点直达对应楼层（\`#/thread/t1#f3\`），js/app.js:117

### P0-2　把市场 ↔ 论坛缝起来（这是「插件生态」论坛的命门）
- \`plugins\` 加 \`slug\`，新增路由 \`#/plugin/:slug\` 详情页（版本历史 / 安装命令 / 兼容宿主 / changelog / 本插件的讨论）
- \`threads\` 补 \`plugin\` + \`pluginVer\`（先补 t2 Blender、t3 pnpm、t6 node-pty、t7 模型时钟），论坛加「按插件筛选」，插件页反向聚合帖子
- 插件卡整块可点、chip 的「查看插件 ›」接上、顶栏搜索按当前路由分发（js/app.js:300、171、930）

### P0-3　修四个正在实时伤害用户的真 bug
- **手机端加导航**：\`position:fixed;bottom:0\` 四项 tabbar（动态 / 市场 / 论坛 / 我），加 \`padding-bottom:env(safe-area-inset-bottom)\`，\`body\` 同步让出等量高度 —— 现在 390px 下市场 / 论坛 / 空间进不去
- \`.col-side\` 假吸顶：\`max-height:calc(100vh - var(--nav-h) - 32px); overflow:auto\`（实测 1362px > 900px）
- 草稿被吃：render 前存 \`S.draft\`，渲染后回填 \`#composer\` / \`#reply\`
- 假按钮：委托层对非 \`a/button\` 的 \`[data-act]\` 统一补 \`role="button" tabindex="0"\`，keydown 把 Enter/Space 映射到同一分支；\`.nav-links a\` 补 \`href\`（约 20 行修 60 个不可达控件）

### P1（下一轮）
字号收敛到 12/13/14/16/20 五档（9.5→11、11.5→12，用 \`font-weight:600\` 拉层级而非缩字号）；\`--txt-3: #5b6e82 → #4a5c70\` 把 4.76~4.98 的徽章一次拉到 6+:1；可点 chip 提到 \`min-height:28px\`（760 断点 32px）；删掉论坛页重复的 tag chips 整行（同名标签与分类 AND 了两次）；每帖写独立正文；\`t.replies\` 与实际楼层数对齐；\`replaceState\` 改 \`pushState\`；列表分页。

### P2（补机制）
信任等级与发帖门槛、@提及与订阅、编辑记录、举报审核队列、真采纳（现在写死 \`t.solved && i === 1\`，js/app.js:552）、新手区 / Bug 反馈 / 插件发布三个板块（\`boards\` 已定义但从未渲染，js/data.js:179-184）、单一登录态加「访客 / 成员 / 版主」三态演示开关。
