## 一句话结论

读的体验够格做用户访谈，当社区骨架不够用——写、身份、已读三条主干一条都没落地。

## 三个最强项

**信息架构把跨域切换压到一次点击。** 左栏固定 rail 把插件市场、论坛热帖、我的空间并到同一层（css/app.css:139），≤1080px 收单栏（css/app.css:776-777），窄屏改整行横滚胶囊条而非隐藏（README.md:107），390px 仍可滑切（shots/f-forum-390.png 顶部）。

**话题行是信息容器，不是标题列表。** 一行含头像、置顶/已解决/新三徽章、标题、摘要、主标签+分类+附加标签、作者与时间、参与者头像堆叠加 `+n`、回复/浏览/点赞三列（js/app.js:387-414）；分类名与主标签同名时去重（js/app.js:404）；窄屏重排两列让标题拿整行（css/app.css:657-662）。

**长帖有真正的阅读器。** 本帖导航按楼生成进度条与逐楼摘要，点楼号跳转并高亮（js/app.js:501-514、800-807）；主楼与每层楼各有五个表情反应，计数随状态增减（js/app.js:376-385）。

## 五个最致命的问题

**1. 只有读路径，没有写路径。** 发新帖、收藏、分享、举报全弹 toast（js/app.js:456、545-546、566）；回复提示"审核后展示"后清空输入框，内容不进楼层（js/app.js:867）；只有动态发帖写进了内存数组（js/app.js:857），刷新即失。→ 连发一帖走通都做不到，所有"128 回复"都是死的。→ 补：回复落进 `fs`、帖子落进 `threads`，先用 localStorage 兜刷新。

**2. 身份与权限不存在。** 用户写死 `u1`（js/app.js:109、857），"版主"只是 CSS 类（js/app.js:72），锁帖是数据里写死的 `closed`（js/data.js:113）。→ 四类角色切不出来，而第一年的日常就是删广告、锁重复帖。→ 补：加 `S.me` 与角色枚举，管理按钮由权限矩阵控制显隐。

**3. 已读与问答状态机缺失。** `unread` 是静态布尔（js/data.js:93、109），进帖不回写，刷新又是 3 条未读；"采纳答案"靠 `t.solved && i === 1` 硬编码到第 2 楼（js/app.js:552）。→ 留存循环与求助闭环两台发动机都没点火。→ 补：`S.read` 集合 + 采纳写回 `t.acceptedFloor`。

**4. 导航历史被覆盖，列表不分页。** 每次 render 都用 `replaceState` 改写 hash（js/app.js:746-748），从列表进帖子后按返回直接离开站点；列表全量 `map`（js/app.js:435-458）；筛选只活在内存（js/app.js:29-31）。→ "读完回列表"是最高频动作，一步就断。→ 补：换 `pushState`+`popstate`，加游标加载更多。

**5. 市场与论坛是两个孤岛。** 插件卡无详情页、无讨论入口（js/app.js:298-311）；帖子里的「查看插件 ›」是纯 span、无 `data-act`、点了没反应（js/app.js:171-172）；两处搜索各写一套 substring（js/app.js:318、424），顶栏搜索回车只跳论坛（js/app.js:930-932）；右栏热门话题把标签当搜索词塞进 `S.q`（js/app.js:808），点进去多是空结果。→ DSH 相对 GitHub 的唯一增量是"版本更新↔踩坑↔作者在楼里回"，这条链断了。→ 补：插件详情页聚合相关帖。

## 缺的关键机制清单

| 机制名 | 现状 | 最少需要做到什么 |
| --- | --- | --- |
| 账号与角色 | 用户硬编码 u1（js/app.js:109） | 访客/成员/作者/版主四态可切 |
| 内容写入 | 回复、发帖、举报只弹 toast（js/app.js:456、867） | 落进列表，刷新不丢 |
| 富文本 | 标"支持 Markdown"（js/app.js:573），正文整体 `esc`（js/app.js:541） | 代码块、行内码、预览 |
| 已读与订阅 | unread 静态（js/data.js:93） | 读后回写、按未读筛选 |
| 问答闭环 | solved 写死（js/app.js:552） | 提问→回答→采纳→结帖 |
| 审核举报 | 举报弹 toast（js/app.js:566） | 举报队列、隐藏锁帖留痕 |
| 搜索 | 市场论坛各写 substring（js/app.js:318、424） | 跨实体统一检索分组 |
| 深链 | 筛选只在内存（js/app.js:29-31），`#app` 空容器（index.html:15） | 筛选进 URL、帖子级静态路径 |

## 若只改三件事

1. **回复真正写进楼层**：`reply` 落进 `fs` 并支持代码块，配 localStorage 兜刷新。
2. **加身份开关**：访客/成员/版主三态，管理按钮由权限矩阵驱动。
3. **换掉 replaceState 并加游标分页**：退后键能回列表、筛选能分享。
