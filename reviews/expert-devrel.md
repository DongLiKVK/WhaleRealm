# 专家评审 · 插件作者 / DevRel 视角

## 一句话结论
能承接"看插件"，接不住"维护插件"：市场是陈列柜，论坛是公告板，中间没有一根数据线 —— 作者发完版本，只能自己去帖子里翻谁踩了坑。

## 我最想要的（现在的站里没有）
1. **`#/plugin/:slug` 详情页**：版本历史、安装命令、兼容宿主、changelog 全无落点；哈希路由只有 feed/market/forum/thread/space 五条（js/app.js:706-716）。
2. **帖子挂插件并标版本**：我要的是"v1.2.0 那个坑"，不是"关于某插件的一句话"。
3. **作者控制台**：我维护的插件 / 未解决 / 待我回复 / 今日星标；现在只有一条静态通知文案（js/data.js:166）加顶栏小红点（js/app.js:108）。
4. **结构化发版**：带版本号与破坏性变更的对象，而不是一条自由文本动态（js/app.js:853-861）。
5. **插件 × 宿主版本兼容矩阵**：站点自己都说"文档永远慢半拍，看 capability"（js/data.js:148），却没地方贴这张表。

## 市场页的五个硬伤
1. **整卡不可点。** 现象：九张卡唯一动作是右下角"安装"。证据：卡根节点无 data-act（js/app.js:300-310），全卡只有 js/app.js:310 一个 install。后果：详情、README、issue 入口零落点，访客看完介绍无处深入。
2. **"查看插件 ›"是死链。** 现象：动态下的插件 chip 明写"查看插件 ›"。证据：文案 js/app.js:171-172，chip 无 data-act，点击委托取不到目标直接 closePop()（js/app.js:753-758）—— 触发一次无意义整页重绘。后果：动态→插件这条唯一明示通路点了没反应。
3. **排序在说谎。** 现象：只有三档。证据：js/app.js:335 仅"热度/最新/安装"，README 宣称四档含星标（README.md:114）；"最新"按 id 字典序倒排（js/app.js:320），"热度"实际按 stars（js/app.js:322）。后果：刚发的 0.9.7 永远排在 3.0.1 后面，作者发版等于没曝光的。
4. **安装是假动作。** 现象：点一下变"已安装"，数字不动。证据：只往 S.installed 塞 id 再 toast"重启后生效"（js/app.js:826-831），安装量仍读静态 p.installs（js/app.js:309）。后果：无版本选择、无命令、无卸载，榜单与转化数据全不可信。
5. **指标写死。** 现象：标题栏"本周新增 4 个"。证据：js/app.js:330 硬编码，js/data.js:16-24 只有 updated 文案、没有时间戳可推导。后果：首屏第一行数字就经不起问，作者也无从判断上新节奏。

## 市场 ↔ 论坛 的联动缺失清单
**核实结果**：posts 每条都带 plugin/pluginVer（js/data.js:29、43、52、63、72），threads 八条全部没有（js/data.js:87-120，字段只有 cat/tag/tags）。
**断层意味着**：t2 Blender 实测、t3 pnpm 拦截、t6 node-pty、t7 模型时钟，本质全是插件帖却挂不上插件 —— 插件页聚合不出"本插件的讨论"，论坛也筛不出"这个插件的 issue"，作者答 issue 只能靠标题文本搜索（js/app.js:421-426 只搜 title/excerpt/tags）。
其余缺口：
1. 市场分类（js/app.js:328）与论坛分类（js/data.js:123-130）是两套词表，无映射。
2. 市场 `#标签` 纯展示（js/app.js:307 的 `<i>`），论坛标签云可点（js/app.js:448-450），同一概念两种待遇。
3. 帖末栏只有"关于作者 / 本帖导航 / 相关话题"（js/app.js:578-595），没有关联插件卡。
4. 顶栏搜索回车只跳论坛（js/app.js:930-931），搜插件名到不了市场。
5. 空间"插件"tab 直接复用市场卡（js/app.js:601-607），在别人空间里也挂着"安装"。
6. 论坛回复不落库，只弹"审核后展示"toast（js/app.js:863-868）—— 作者连答案都留不下。

## 若只改三件事
1. plugins 加 slug，pageHTML() 与 applyHash() 各加一条 `#/plugin/:slug`，卡片整块可点、chip 的"查看插件 ›"接上。
2. threads 补 plugin/pluginVer（先填 t2/t3/t6/t7），论坛加插件筛选，插件页反向聚合帖子。
3. "最新"改按 releasedAt 时间戳排序，"本周新增 N 个"由数据算出。
