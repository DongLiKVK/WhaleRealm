# 专家评审 · 插件作者 / DevRel 视角

对象：`qqspace-dsh` 静态前端（鲸域 · DSH 开发者论坛与聊天社区）。判据只有一条：我是第一个把插件搬来的作者，会不会留下来。

## 一句话结论

市场能让人「看见」9 个插件，却没有一处让人「信任」其中一个——卡片回答不了"装了会不会崩、怎么升级、出问题找谁"，唯一可点的按钮点完就把你钉成"已安装"，此后再不提新版。**演示层优等生，作者回路是空的**，我第一天就会回自己 README 里去。

## 作为插件作者我最想要的（现有 / 缺失）

- **被人找到**：有三级入口（安装榜、插件推荐、"查看插件 ›"），但全部失效——点击只回市场首屏，不定位插件（`js/app.js:280`、`347`、`171-172`）。
- **敢装的信息**：只有名字/作者/版本/两行简介/3 个 tag（`js/app.js:298-311`），简介还被 `-webkit-line-clamp:2` 截断（`css/app.css:459`）。无兼容宿主、无依赖、无截图、无评分。
- **详情页**：不存在。卡片无 `data-act`，整张不可点（`js/app.js:300`）。
- **版本历史 / changelog / 破坏性变更**：无字段，全库 grep `changelog`=0、`破坏性`=0（`js/data.js:15-25` 仅 13 个字段）。
- **升级通路**：没有。按钮写死「安装 / 已安装」两态（`js/app.js:310`、`826-831`）。
- **反馈落回作者**：帖子与插件之间没有关联字段（`js/data.js:87-120`），issue 无处可挂。
- **发版仪式感**：只能混进动态流，正文里"升级方式"是一行纯文本（`js/data.js:30`）。

## 市场页的五个硬伤

1. **卡片是海报不是说明书。** 运维类 `dsh-remote-deploy`、逆向类 `rea-toolbelt` 的风险高一个量级，却和 `dsh-badge` 共用同一套字段——数字一样多，判断成本完全不同。
2. **所有入口都指回列表顶部。** 安装榜 5 行、首页插件推荐 4 行、动态里的「🧩 插件名 · 查看插件 ›」，点了要么死、要么 `data-route=market`（`js/app.js:280`、`347`、`171-172`）。找插件最贵的一次浪费，就是点了名字被送回首屏。
3. **分类不贴合生态。** `['创作','效率','界面','运维','逆向']`（`js/app.js:328`）里，`dsh-model-clock` 与 `dsh-our-free-model` 两个模型路由插件都挤在「效率」；「逆向」只 1 个却占一整格；高频的"发布/构建""连接器/MCP""模型与路由"没有位置。5 类 9 插件，平均 1.8 个/类——不是导航，是装饰。
4. **排序在说谎。** 「最新」按 `id` 倒序（`js/app.js:320`），id 是 `p1..p9`，等于按最旧排；卡片印着"2 小时前 / 6 天前"（`js/app.js:305`）却没有"最近更新"排序；"共 9 个插件 · 本周新增 4 个"硬编码（`js/app.js:330`）。
5. **搜索是陷阱。** 市场内只匹配 name+desc+tags（`js/app.js:318`），搜作者名零结果；顶栏全局搜索回车一律跳论坛（`js/app.js:930-931`）——在市场页按回车，人被送去论坛。

## 市场 ↔ 论坛 联动缺失清单

- **发版帖没有插件锚点**：`threads` 无 `plugin` 字段（`js/data.js:87-120`），t2 的 Blender 实测、t5 的逆向 3.0 迁移无法反链回 `dsh-blender-plugin` / `rea-toolbelt`。
- **没有「本插件的讨论」**：插件详情页缺位，issue 集合无处收；帖子右栏"相关话题"按数组顺序取前 4，不看标签也不看插件（`js/app.js:590`），本可按 plugin/tag 交集排。
- **没有「发版」维度**：标签条只有 公告/经验/求助/讨论/教程/周报（`js/app.js:417`），公告位被官方占着（t1 手册、t8 周报），作者版本公告只能挤进"公告"，信号被稀释。
- **版块缺三类**：插件发布 / Bug 反馈 / 招募。现 6 类里「灌水闲聊」0 帖；`js/data.js:179-184` 的 `boards`（含"问题反馈 62"）定义了却从未渲染。
- **作者收不到回音**：消息中心 4 行全是死链（`js/app.js:117`），"我的插件"点开是市场（`js/app.js:126`）。

**区分**：真实版本号聚合、依赖树、兼容矩阵、评分、issue 写回属于**需要后端**；详情页骨架、卡片可点、按 updated 排序、搜索覆盖作者、加两个字段、发布入口都是**前端没做**，零后端也能演。

## 如果只改三件事

1. **给插件一张详情页，让名字可点。** 路由 `#/plugin/p1`，版式直接复用帖子详情（左正文右 sidebar 已成熟），先塞 README / 截图 / changelog 三段假数据；安装按钮改两态：`安装` → `已安装 · 升级到 v2.1.0`。一次解决"敢不敢装"和"作者为什么回来再看一眼"。
2. **把发版帖变成一等公民。** `threads` 加 `plugin`/`ver`/`breaking`，列表行标题右侧渲染 `🧩 dsh-blender-plugin v2.1.0` chip 直达详情；发版帖模板固定四段：版本号 / 破坏性变更 / 升级命令 / changelog。作者第一次会觉得"发版在这里有位置"。
3. **修三个入口 + 一次排序。** 安装榜、插件推荐、"查看插件 ›" 全改 `data-act="plugin"` 直达；「最新」按 `updated` 排；市场搜索覆盖 author、顶栏回车按当前路由分发。不到 30 行，但它就是"我能不能被找到"的答案。
