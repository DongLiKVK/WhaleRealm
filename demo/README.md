# 鲸鱼娘即状态 · Demo

把 `whale/` 里那 105 段动作从「随机装饰」改成「界面状态机」的最小可跑验证。

## 怎么跑

```bash
# 仓库根目录
python -m http.server 8790 --bind 127.0.0.1
# 打开：http://127.0.0.1:8790/demo/whale-states.html
```

必须走 HTTP，不能双击（`file://` 下同源 iframe 读不到 `__whale`）。

| 状态 | 片段 | 语义 | 播放方式 |
| --- | --- | --- | --- |
| 待机 | c033 待机呼吸休闲 | 什么都没发生 | 循环 |
| 思考 | c068 深度思考碎碎念 | 请求发出去还没回来 | 循环 |
| 忙碌 | c048 工作状态-忙碌点按 | 批量处理中 | 循环 |

| 惊喜 | c057 蓝鲸现世 | 低频彩蛋 | 一次性定格 |

## 三条实现要点

1. **两种播放语义**。持续态（待机/思考/忙碌）钉住 `loop=true`；一次性态在片尾 120ms 内 `pause()`，`ended` 不触发，卡片自带的「演完掷骰换下一段」就不会把状态抢走。**不要用 seek** —— 改 `currentTime` 会让解码器重定位，末帧反而被冲掉。
2. **按需加载**。只在切换前加载目标片段；105 段共 59.5 MB，全量预取会毁掉首屏。
3. **离屏即停**。真实 `IntersectionObserver` 判定舞台可见性，滚出视口立刻暂停并在读数条上标出来。卡片内部也已有 `onScreen()` 走 frameElement 的 rect，两层不冲突。

## 对照

右上「现在的随机池」按钮切到现状：演完自动掷骰、语义消失。演示页右侧事件流会记录每次切换，方便对比两种模式的观感差异。

## 已知取舍

- 演示页只用了 8 段；池子里还剩 97 段未被这次的语义映射覆盖（`余额-*` 6 段、`吃喝` 19 段、节令 8 段、才艺 26 段等）。
- 一次性态定格是「停在收尾前一帧」，不是干净的末帧；要做真末帧得靠 `requestVideoFrameCallback` 预取，或把片段重编码成「首尾可停」的两段式素材。
