## 二、变更明细

### 1. SSH

新增 `/etc/ssh/sshd_config.d/00-hardening.conf`（600）：

```
PermitRootLogin prohibit-password
PasswordAuthentication no
KbdInteractiveAuthentication no
PubkeyAuthentication yes
MaxAuthTries 3
MaxSessions 4
LoginGraceTime 20
X11Forwarding no
AllowAgentForwarding no
ClientAliveInterval 300
ClientAliveCountMax 2
```

同时把 `/etc/ssh/sshd_config.d/50-cloud-init.conf` 的 `PasswordAuthentication yes` 改为 `no`，避免 cloud-init 配置与加固配置打架。文件按字母序加载，00 先于 50。

校验（`sshd -T`）：`passwordauthentication no`、`permitrootlogin without-password`、`maxauthtries 3`、`x11forwarding no`。本机回环用 `PreferredAuthentications=password PubkeyAuthentication=no` 测试，返回 `Permission denied (publickey)`，确认口令通道已关闭；密钥连接正常。

### 2. fail2ban

`/etc/fail2ban/jail.local`：

- DEFAULT：`bantime 1d`、`findtime 1h`、`maxretry 4`
- `[recidive]`：1 周 / 1 天 / 3 次
- `[nginx-req-limit]`：新增 `/etc/fail2ban/filter.d/nginx-req-limit.conf`，匹配 nginx `limiting requests ... client: <HOST>`，10 次/10 分钟封 1 天

运行态 3 个 jail 全部 active：sshd、recidive、nginx-req-limit。历史攻击 IP 179.43.153.2、92.118.39.71 仍在封禁列表。

### 3. nginx

- `/etc/nginx/snippets/jingyu-security-headers.conf` 增加 `Strict-Transport-Security "max-age=15552000" always`（首阶段 180 天，不含 includeSubDomains，确认全站 HTTPS 后可加到 1 年）

`nginx -t` 通过并 reload；`curl -I --http2` 返回 `HTTP/2 200`、`server: nginx`、HSTS 与全套安全头。
