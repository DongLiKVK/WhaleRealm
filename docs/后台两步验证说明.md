# 后台两步验证（2FA）使用说明

> 适用：`https://whalerealm.top/admin/`。后台账号体系与站点前台完全独立。
> 代码与契约：`admin/js/shell.js`、`server/src/routes/admin-auth.js`、`docs/admin-api.md` 第 1.1 节。

## 1. 谁必须开

| 角色 | 策略 |
| --- | --- |
| `owner`（超级管理员） | 强制。下次登录必须扫码绑定，不能跳过 |
| `admin`（管理员） | 强制。下次登录必须扫码绑定 |
| `editor` / `staff` / 自定义角色 | 可选。不强制，登录只输密码 |

绑定状态在「权限管理 → 管理员账号 → 两步验证」列查看；`owner` / `admin` 显示「未绑定」时，下一次登录会被拦到绑定页。

## 2. 第一次登录（绑定）

1. 打开 <https://whalerealm.top/admin/>，输入账号密码。
2. 页面进入「绑定两步验证」，出现二维码和一行大写密钥。
3. 用验证器 App 扫码：Google Authenticator、Microsoft Authenticator、1Password、Bitwarden 等都可以。扫不了就手动输入密钥。
4. 输入 App 显示的 6 位数字，点「验证并登录」。
5. 页面给出 **8 个恢复码**（格式 `XXXX-XXXX`）。现在抄到离线位置（密码管理器 / 打印），勾选「我已保存这些恢复码」，再进控制台。

> 恢复码只显示这一次。服务端只存哈希，事后无法再查。

## 3. 日常登录

1. 账号密码通过后，进入「两步验证」。
2. 输入 App 当前的 6 位数字，点「验证并登录」。
3. 同一个 6 位码不能连续用两次；如果提示「这个验证码刚用过」，等下一个 30 秒再试。
4. 手机不在身边：点「使用恢复码」，把 `XXXX-XXXX` 填进同一个输入框。每个恢复码只能用一次。

验证码错误与密码错误共用失败次数：连续 5 次锁 15 分钟。锁定期内正确密码也会被拒。

## 4. 换手机 / 丢失验证器

### 还有恢复码

登录时点「使用恢复码」，用掉一个。进入后台后，建议尽快重新绑定：

- 让另一个管理员在「权限管理 → 管理员账号」点「重置两步验证」，你下次登录重新扫码；
- 或调用 `POST /api/admin/auth/2fa/recovery-codes`（需要密码 + 当前验证码）重新生成 8 个恢复码。

### 恢复码也没了

**优先找另一个管理员**：权限管理 → 管理员账号 → 目标账号 → 「重置两步验证」。不能重置自己，这是故意的。

**只剩自己**：登录服务器执行

```bash
cd /var/www/jingyu/server
sudo -u jingyu env DB_PATH=$PWD/data/jingyu.db node scripts/reset-admin-2fa.js root
```

脚本会清空该账号的 TOTP secret 与恢复码、撤销全部后台会话。之后重新登录，会回到扫码绑定流程。

## 5. owner / admin 不能自己关 2FA

`POST /api/admin/auth/2fa/disable` 对 `owner` / `admin` 一律返回 `403`，避免有人用一次密码会话把最重权限降级。确需关闭只能先改角色，或由另一个管理员重置。

## 6. 运维注意

- 环境变量 `ADMIN_TOTP_KEY` 是 secret 的加密密钥，**与 `JWT_SECRET` 独立**。不要更换；换掉等于所有已绑定账号的 secret 作废。
- 备份数据库时把 `ADMIN_TOTP_KEY` 一起离线保存；只恢复数据库、不恢复密钥，2FA 账号会解不开。
- 验证码接口限流：`verify` / `enable` 30 次 / 5 分钟 / IP，`disable` / `recovery-codes` 20 次 / 5 分钟 / IP。
- 日志动作：`auth.2fa_enroll`、`auth.2fa_enable`、`auth.2fa_fail`、`auth.2fa_recovery`、`auth.2fa_recovery_codes`、`auth.2fa_disable`、`auth.2fa_reset`。

## 7. 本地联调

`qa/admin-e2e.mjs` 会自动完成首次绑定，secret 缓存在 `qa/.admin-2fa-secrets.json`（0600，已 gitignore）。
重置本地账号：

```bash
DB_PATH=data/admin-lead.db ADMIN_TOTP_KEY=local-e2e-totp-key node scripts/reset-admin-2fa.js admin01
```

截图工具 `tools/admin-shot.mjs` 已支持自动过 2FA；也可显式给 `--secret BASE32`。
